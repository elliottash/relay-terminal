Three decisions shape the mail design:

1. **Providers for the first version.** Recommendation: Gmail API only (your working skill already uses it); IMAP/Outlook as a later provider behind the same `mail_*` tools.
2. **Whose OAuth client.** (a) Relay registers its own Google OAuth app, which is one-click for users but needs Google's verification and a paid security assessment for restricted Gmail scopes; or (b) bring-your-own client ID (each user creates a Google Cloud client), which is free and fits BYOK but is a hard first run. Recommendation: (b) for now with a guided setup, and (a) as a business decision when mail becomes a starter task.
3. **What the agent may do.** Recommendation: search, read, label, archive and draft; **no send** in the first version (drafts only, the person sends), revisited once live cases have a track record.
