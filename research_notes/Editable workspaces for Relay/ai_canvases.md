# AI document canvases relevant to Relay (23 September 2026)

## What is ChatGPT's current editing model, and where does the older Canvas fit?

### Takeaway
As of 23 September 2026, the older side-by-side ChatGPT Canvas is a **legacy-model workflow**, while newer models use editable writing and code blocks inside chat. The distinction matters more than a feature-by-feature description of the 2024 Canvas: OpenAI says Canvas stopped being available in GPT-5.5 Instant and Thinking on 28 May 2026, with temporary access through paid users' legacy models. [OpenAI model release notes](https://help.openai.com/en/articles/9624314); [OpenAI Support, 7 September 2026](https://community.openai.com/t/canvas-document-will-be-gone-with-5-4/1386370/14)

### Cited Findings
- **Historical Canvas (launched 3 October 2024):** a separate side-by-side surface where the user could directly edit text or code, highlight a section to focus ChatGPT's response, receive inline feedback and suggestions, use writing and coding shortcuts, and restore earlier work with a back button. This describes the older Canvas, not guaranteed current-model behavior. — [OpenAI launch post](https://openai.com/index/introducing-canvas/)
- OpenAI's own Academy guide, last updated 29 May 2026, also describes `/canvas` or the composer menu to start a canvas, direct editing, highlighted passages for AI suggestions, export/share, and version history. Its general language conflicts with the more specific 28 May model release note; interpret it as describing the legacy Canvas path. — [OpenAI Academy Canvas guide](https://academy.openai.com/en/public/clubs/work-users-ynjqu/resources/canvas); [OpenAI model release notes](https://help.openai.com/en/articles/9624314)
- **Current writing blocks:** ChatGPT may put draft emails, posts, or documents into editable blocks within a chat response; a user can also request an editable draft. Depending on block and account, one can edit text directly, ask ChatGPT to revise selected text or the entire draft, open full-screen, undo/redo recent AI-assisted edits, copy text, and save supported document drafts to Library. Common rich-text formatting includes headings, links, lists, checklists, bold, and italic. Edits save to the conversation after a short delay, and follow-up prompts can use the latest version; Temporary Chat edits may not persist after the conversation ends. — [OpenAI writing and code blocks help](https://help.openai.com/en/articles/20001246-working-with-writing-blocks-and-code-blocks-in-chatgpt)
- **Current code blocks:** supported blocks allow direct code edits and prompts to edit code. Where available, Code/Preview switches render HTML, React, SVG, Mermaid, and Vega/Vega-Lite; supported Python blocks run in a sandbox with console output. A preview may ask permission to reach external resources. — [OpenAI writing and code blocks help](https://help.openai.com/en/articles/20001246-working-with-writing-blocks-and-code-blocks-in-chatgpt)
- OpenAI explicitly says actions vary by plan, device, workspace settings, model, and rollout. The writing-block documentation does **not** assign its actions separately to web, macOS, Windows, or mobile, so a per-platform feature matrix would be unverified. — [OpenAI writing and code blocks help](https://help.openai.com/en/articles/20001246-working-with-writing-blocks-and-code-blocks-in-chatgpt)
- The new ChatGPT desktop app on macOS and Windows includes Chat, Work, and Codex; ChatGPT Classic can remain installed beside it. Work creates documents and other files, and cloud Work chats sync across web, mobile, and desktop. Codex works with local files and repositories, but that statement is about Codex, **not** a claim that ChatGPT writing blocks or Work documents live-sync local files. — [OpenAI desktop migration help](https://help.openai.com/en/articles/20001276/)

### Inferences
- The older Canvas is still useful as an interaction reference for Relay's side-by-side editor, but OpenAI's active model trajectory is toward edits embedded in chat; label screenshots and descriptions by model and date.
- Writing-block undo/redo is narrower evidence than a browseable document history or a visual diff. Local filesystem mirroring is not established by OpenAI's documentation for either writing blocks or legacy Canvas.

### Gaps
- No current primary document found that confirms a block-level visual diff, durable named version history, export format matrix for writing blocks, or automatic two-way local-file sync.
- OpenAI's writing-block help does not confirm whether the same editing controls appear in the new desktop app, Classic, web, and mobile; it explicitly says availability varies by device and rollout.
- The old Canvas help URL returned 404 when checked on 23 September 2026; OpenAI's launch post and the dated Academy guide are the accessible primary descriptions of that older interaction.

## How do Claude artifacts and Claude Docs handle direct editing, simultaneous work, selection, history, and export?

### Takeaway
Claude's **new Docs beta** is the strongest documented example of direct human edits alongside an AI actively editing the same cloud document, including real-time human collaboration and text-anchored `@Claude` comments. Its explicit current limitation is no version history. The current artifacts guide describes a different, chat-linked document model. [Claude Docs guide](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs); [Anthropic artifacts guide](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them)

### Cited Findings
- **Claude Docs beta:** available on Pro, Max, Team, and Enterprise, with Enterprise owner enablement and exclusions for CMEK, ZDR, and HIPAA-ready configurations. A doc is a rich-text cloud document in the Artifacts tab; it can contain headings, tables, multiple tabs, and material from files, projects, memory, skills, or connected apps. — [Claude Docs guide](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs)
- The Docs guide explicitly says nothing is locked while Claude works: people may click and type at any time. Edits autosave and appear to everyone viewing the doc, and editors can work simultaneously with each other and Claude. Claude edits only when a signed-in person asks, acts with that person's permissions, and changes are attributed to human or Claude. — [Claude Docs guide](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs)
- Doc editing requests can be sent in chat or placed on selected text as a comment mentioning `@Claude`; Claude replies, edits, and explains its action. Claude also leaves drafting comments explaining choices or questions. This is an anchored comment workflow, not documented as an accept/reject diff. — [Claude Docs guide](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs)
- Docs export to Word, PDF, Markdown, or Google Docs. **Version history is explicitly unavailable** in the beta; charts and diagrams do not refresh automatically from connected data, and doc edit/comment activity is not yet logged in Anthropic's Compliance API. — [Claude Docs guide](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs)
- On Claude web and Desktop, users can create and edit Docs. Claude Code can create one; in its desktop context the doc opens in a side panel, while the terminal gives a web link. iOS/Android can request and view docs but must switch to web or Desktop to edit, start from a template, or change sharing. — [Claude Docs guide](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs)
- **Artifacts, as distinct from Docs:** Anthropic identifies artifacts made in a chat before 16 September 2026 as “legacy artifacts”; they remain usable/shareable but users cannot make new legacy artifacts. New template artifacts can be edited directly, including typing in a doc, while also asking Claude to edit them. In a doc or Markdown artifact, highlighting text and choosing “Edit with Claude” scopes the request to that text. Template Docs export to Word/PDF/Markdown/Google Docs; legacy artifacts can be viewed as code, copied, or downloaded. — [Anthropic artifacts guide](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them)
- The current artifacts guide says editing an earlier chat message creates a different chat history with its own artifacts; it does **not** document an artifact version selector. The newer Docs guide explicitly says its living Docs have no version history. An older cached copy of the artifacts help text did mention a version selector, but the live page checked on 23 September 2026 does not; do not treat that historical control as verified current behavior. — [Anthropic artifacts guide](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them); [Claude Docs guide](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs)

### Inferences
- Docs demonstrate an explicit concurrency contract that Relay could emulate: no editing lock, autosave, attribution, and AI edits made under the requesting person's permissions.
- The absence of Docs version history raises the value of a recoverable local document and clear per-edit review in Relay, but Anthropic's docs do not state its conflict-resolution algorithm.

### Gaps
- Anthropic does not document a Docs visual diff, per-change accept/reject control, conflict handling when a human and Claude edit exactly the same text at once, or automatic two-way synchronization with a local path.
- Export is documented as a one-time operation; no primary source found that describes exported files continuing to sync with a Doc.

## What does Gemini Canvas expose for documents and previews?

### Takeaway
Gemini Apps Canvas on the web combines a directly editable, autosaved document with selection-scoped AI requests and saved-version arrows; code/app canvases add previews and a “recent changes” view. The consumer and Gemini Enterprise Business Canvas docs differ on export formats and session limits, so they should not be merged. [Gemini Apps Canvas help](https://support.google.com/gemini/answer/16047321?hl=en); [Gemini Enterprise Business Canvas help, 24 July 2026](https://support.google.com/g/answer/16914858?hl=en)

### Cited Findings
- In Gemini Apps on a computer, one starts at `gemini.google.com`, chooses Canvas, optionally uploads files, and creates a document, app, slide, or code. Document text can be directly edited or changed via prompt; edits autosave. Selecting text then entering a prompt scopes an edit, and a “Suggest edits” action is offered for selected text. Length/tone controls and a formatting toolbar are also available. Previous/Next version controls display saved document versions. — [Gemini Apps Canvas help](https://support.google.com/gemini/answer/16047321?hl=en)
- For app/code canvases, users can edit code directly in Code view, switch to a running preview, inspect preview errors/logs via Console, use “Show recent changes,” and use a separate Select and ask mode for a selected app section. The Google help page describes “Show recent changes” for **code**, not a document diff. — [Gemini Apps Canvas help](https://support.google.com/gemini/answer/16047321?hl=en)
- Consumer Gemini Apps Canvas exports text to a new Google Doc or copies content. Its help page also describes PDF export with preview for a document containing LaTeX. Shared Canvas links open on `gemini.google.com`, not in the Gemini mobile app; a recipient can copy shared content to continue editing in their own Canvas. — [Gemini Apps Canvas help](https://support.google.com/gemini/answer/16047321?hl=en)
- The **separate Gemini Enterprise – Business edition** Canvas guide, explicitly updated 24 July 2026, documents direct Markdown editing, selection-to-`Ask Gemini`, saved-version arrows, and export to Google Docs, DOCX, or PDF. It says Canvas editing is supported only for content generated during the active session; later edits require export to another application. This active-session restriction is evidenced for that Business edition, not established for consumer Gemini Apps Canvas. — [Gemini Enterprise Business Canvas help](https://support.google.com/g/answer/16914858?hl=en)
- In that Business edition, slides are not directly edited in place: each prompted update produces a new artifact rather than a version of the prior slides, and export goes to Google Slides, PowerPoint, or PDF. This is a format-specific limit, not a document limit. — [Gemini Enterprise Business Canvas help](https://support.google.com/g/answer/16914858?hl=en)

### Inferences
- Gemini's document version arrows are recovery/navigation evidence, while code “recent changes” is the closer diff analogue. The docs do not establish a user-reviewed patch before a document AI edit is applied.
- Export to Google Docs is a handoff; neither the consumer nor Business guide describes a live link to a local file after export.

### Gaps
- No official consumer Gemini Apps source found that defines version granularity, merge behavior for simultaneous manual and AI edits, a document-specific before/after diff, or two-way local-file sync.
- The consumer help page specifies browser `gemini.google.com` for creation and says shared Canvas links cannot open in the mobile app; it does not establish equivalent editing in a native desktop app.

## Which other major canvases offer useful interaction patterns?

### Takeaway
Microsoft Copilot Pages offers a durable side-by-side, multi-user page with **selection-specific proposed revisions that require Apply/Reject** and recoverable earlier versions. Notion AI offers selected-text edits with Accept/Discard/Try again inside a general-purpose editor whose page history shows change highlights. [Microsoft Copilot Pages help](https://support.microsoft.com/en-us/microsoft-copilot/using-copilot-pages); [Microsoft version restoration](https://support.microsoft.com/en-us/microsoft-365-copilot/view-or-restore-an-earlier-version-of-your-microsoft-365-copilot-page); [Notion AI guide](https://www.notion.com/help/guides/notion-ai-for-docs); [Notion version history](https://www.notion.com/help/duplicate-delete-and-restore-content)

### Cited Findings
- **Copilot Pages:** from a Copilot answer, select “Edit this response” to create or append to a page. The page opens beside chat, supports direct rich-text editing and autosave, and Copilot can add or update content. In the consumer Pages editor, placing the cursor or highlighting text and selecting “Ask” opens a page-linked chat; Copilot proposes a revision to the highlighted section in a panel, which the user **applies or rejects**. — [Microsoft consumer Copilot Pages help](https://support.microsoft.com/en-us/microsoft-copilot/using-copilot-pages)
- **Microsoft 365 Copilot Pages:** Microsoft describes persistent pages, direct edits at any time, and real-time team collaboration. It says AI replies may not reflect simultaneous edits by multiple people until the page is refreshed or Copilot is re-engaged. The underlying formats are `.page` and `.loop`; data scope is primarily Microsoft 365, with third-party sources possibly incomplete. — [Microsoft 365 Copilot Pages overview](https://support.microsoft.com/en-us/microsoft-365-copilot/how-microsoft-365-copilot-pages-works)
- Microsoft documents previous/next version arrows and “Restore version” for Copilot Pages. It also documents converting a Page to a Word document in Word for the web and converting one to PDF; those are export/conversion paths, not documented local-file synchronization. — [Microsoft version restoration](https://support.microsoft.com/en-us/microsoft-365-copilot/view-or-restore-an-earlier-version-of-your-microsoft-365-copilot-page); [Word conversion](https://support.microsoft.com/en-us/microsoft-365-copilot/convert-your-microsoft-365-copilot-page-to-a-word-document); [PDF conversion](https://support.microsoft.com/en-us/topic/convert-your-microsoft-365-copilot-page-to-a-pdf-file-d882cadb-c905-4027-b79a-3bacc3348097)
- **Notion AI:** the Notion page remains the editor. Highlighted text offers “Edit with AI”; a user can request a rewrite, then accept, discard, or try again. Notion Agent can separately create or edit pages and databases with the user's permissions. — [Notion AI writing guide](https://www.notion.com/help/guides/notion-ai-for-docs); [Notion Agent help](https://www.notion.com/help/notion-agent)
- Notion page history records a version every 10 minutes during active editing and another two minutes after the last edit. It can show highlights of added/removed/changed text and restore a prior version, with retention limits by plan; Notion warns highlights do not capture every single change. Export offers PDF, HTML, and Markdown/CSV. These are general page capabilities rather than AI-specific versioning. — [Notion page history](https://www.notion.com/help/duplicate-delete-and-restore-content); [Notion export help](https://www.notion.com/help/export-your-content)

### Inferences
- Copilot Pages provides the clearest primary-source pattern for user approval of a localized AI rewrite; Notion provides a similarly simple proposal choice plus stronger general change highlights.
- Across these cloud editors, export is well documented but live, bidirectional synchronization with a local filesystem path is not. A Relay local-file canvas would be meaningfully different if it could preserve editor selection, AI patch review, and outside-file changes together.

### Gaps
- Microsoft's documentation does not specify a character-level diff for the proposed revision panel, an automatic local-file mirror, or exact conflict resolution when two editors and Copilot alter the same span.
- Notion's docs do not establish whether AI-generated inline edits are represented as a special version-history event, or whether exported Markdown remains linked to the page.
