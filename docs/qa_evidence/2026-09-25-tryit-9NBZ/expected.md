# Expected — sealed until the person answers #9NBZ

With the Parallax card open, Ctrl+F opens a slim find strip directly above the card's text —
nothing else on the page moves, and before it is asked for the strip is not there at all.

Typing `parallax` jumps to the first of the word's three places in the card and the strip's
right side reads `3 matches`. Enter (or the ↓ button) steps to the second, then the third, and
a further Enter wraps back to the first — the last match is not a dead end. Shift+Enter (or ↑)
steps backwards the same way. Typing a word the card does not contain reads `No matches` and
moves nothing.

Esc (or the × on the strip) closes the strip and puts the keyboard back on the card being
read. On the board's list page — no card open — Ctrl+F focuses the filter box that `/`
already focuses, selected, ready to type.

In a terminal pane in the same window, Ctrl+F still opens the terminal's own find bar, as
before; the board never steals the key from it.
