# Expected result (sealed until the person answers)

In a focused prompt, Ctrl+Z undoes the last text edit and the first Ctrl+Shift+Z
redoes it. A second Ctrl+Shift+Z restores the newest closed pane, tab, or window
if one exists. Typing more text after undo, or moving focus out of the text field
and back, makes Ctrl+Shift+Z restore closed instead of redoing the old text.
