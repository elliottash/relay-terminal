# expected — #G2C7 (sealed)

Opening Sessions (sessions.open) on a build at or after 64c95e0a shows the header
labels Session/Updated/Turns/Requests/Model/Tokens/Recap, clickable to sort, and
each session as a block whose title spans the full width above one small line of
values aligned under those labels, with tags and the opening prompt (or the code
chips and a snippet) beneath.

Typing three letters into the filter reshapes the list with no perceptible wait:
rows whose titles match appear first — an exact title above the rest — with each
occurrence of the typed words washed inside the title. After the SQLite pass
answers, full-text matches join below, deduplicated, and such a row's second line
is the line that matched, the matched words washed inside it. Clearing the box
restores the plain list.

Typing a #card code filters instantly to the sessions that mention it. Those rows
show their codes as chips before the snippet; codes whose card is claimed now or
was claimed once are boxed and bold, the rest plain. Lowercase typing finds the
same rows.

Typing the same words into the Board pane's filter ranks each section: an exact
card title first, then titles carrying the words, then cards only the body
matched — those show the matched body line under the row, washed. Clearing the
filter returns the columns to their own order.
