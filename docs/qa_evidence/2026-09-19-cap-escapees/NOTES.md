# #Y4RX — capping the programs that leave their pane: implementer evidence

2026-09-19, Claude Fable 5.1. Not a QA verdict.

## The mechanism, from systemd's own documentation

`man systemd.unit`, drop-in section, on this machine (systemd 255):

> Moreover for unit names containing dashes ("-"), the set of directories generated by repeatedly
> truncating the unit name after all dashes is searched too. Specifically, for a unit name
> foo-bar-baz.service not only the regular drop-in directory foo-bar-baz.service.d/ is searched but
> also both foo-bar-.service.d/ and foo-.service.d/.

So `tmux-spawn-.scope.d/` covers every `tmux-spawn-<uuid>.scope`, and
`app-com.google.Chrome-.scope.d/` every `app-com.google.Chrome-<pid>.scope`.

## The live check, and exactly what was done to the real user dir

`~/.config/systemd/user/` held `llama-bonsai.service`, `default.target.wants/` and
`timers.target.wants/`, and no `*.scope.d` directory. The check was:

1. `mkdir -p ~/.config/systemd/user/tmux-spawn-.scope.d` and wrote `relay.conf` there with the
   marker comment line, `[Scope]`, `MemoryMax=1G`, `MemorySwapMax=512M` (1G rather than the real
   default, so the value could not be mistaken for something already in effect).
2. `systemctl --user daemon-reload`.
3. `systemd-run --user --scope --unit=tmux-spawn-relaytest-1311361 -q -- sleep 5 &`, then
   `systemctl --user show tmux-spawn-relaytest-1311361.scope -p MemoryMax -p MemorySwapMax -p DropInPaths --value`:

   ```
   1073741824
   536870912
   /home/elliott/.config/systemd/user/tmux-spawn-.scope.d/relay.conf
   ```

   A transient scope created by a program that is not Relay therefore does pick the drop-in up, by
   prefix, with no unit file of its own.
4. The throwaway scope ended on its own (`sleep 5`), then `rm -rf
   ~/.config/systemd/user/tmux-spawn-.scope.d` and `systemctl --user daemon-reload` again.
   `ls -la ~/.config/systemd/user/` afterwards shows the three original entries and nothing else:
   **nothing Relay wrote is left in the real user directory.** No Chrome drop-in was ever installed
   there, and no long-lived scope was touched.

## Unit test

`tests/escapeecaps_test.cpp` (ctest case `escapees`) runs entirely against a `QTemporaryDir` config
root: paths, file text, install, remove, idempotence, and that a file without Relay's marker line is
neither overwritten nor removed. `ctest -R escapees` on the landed tree: passed.
