## Per-item verdicts

**1. Tests pass — PASS.** `./build/relay-paneusage-tests`: `Totals: 24 passed, 0 failed, 0
skipped, 0 blacklisted`. The three named tests pin exactly what the card claims:
`tabPercentsAreTwoDigitsWide` (`formatPercent2` → `00`, `01`, `05`, `10`, `12`, `99`, `100`),
`oneWordingInEveryPlace` (`tabSuffix(idle)` = `tabSuffix(Sample{})` = `"  ·  cpu 00% · mem 00%"`,
both halves always, busy and idle suffixes the same size, while `readingText`/`liveTag` keep the
quiet-half-out rule), `theTabAverageComesFromAWindow` (empty window → invalid sample → `00/00`;
the mean of what the window holds; an entry older than `kTabWindowMs` drops out of the average;
invalid samples keep their place in time but their numbers are not averaged; `clear()`).

**2. Idle keeps the suffix at 00/00 while the chip disappears — PASS.** Live: with all load dead
the tab still OCRs `pj (2) · cpu 00% · mem 00%` (`qa-codex-tab-idle.png`), and the pane header
crop at the same moment (`qa-codex-idle-header.png`) contains no cpu/mem/percent text at all —
the chip's `worthShowing()` floors still rule it. The implementer's pair
(`implementer-tab-idle.png` / `implementer-idle-header.png`) shows the same. The label is never
empty for a terminal tab: `tabUsageSuffix()` returns a suffix whenever a leaf is a `Pane`
(seeding from the live sample before the first poll), `refreshPaneStatus()` keeps the previous
text between 5 s takes, and the clear branch runs only when the meters are off or the tab has no
terminal pane; every live OCR of a terminal tab in this run shows a suffix.

**3. At most one move per 5 s, showing the 5 s mean — PASS.** Live re-run (real wall-clock
stamps in `qa-codex-cadence.log`; the implementer's `t+N` labels are nominal — the loop's OCR
adds seconds to every step):
- `still` stage: 8 crops over 10.80 s at steady load (30 %/05 %), **pixel-identical in every
  one** — not a 2.5 Hz repaint.
- `halved` stage: the load halves on a signal and the label steps exactly twice in ~14 s:
  `cpu 30%` → `cpu 29%` → `cpu 15%`, standing still between moves. The first take after the
  halving reads **29 %, the window's mean, not the ~15 % the pane measures then** — the 5 s
  averaging the owner asked for (implementer's log shows the same shape: 30 → 28 → 15).
- Spacing: the two moves are bracketed by crops to real times ∈ (…917.40, …918.95] and
  (…922.01, …923.56], i.e. 3.1–6.2 s apart at crop resolution alone; the ≥5 s half is guaranteed
  by the code — a move requires `now - state.labelledAtMs >= kTabUpdateMs` (5000 ms) and
  `labelledAtMs` is set at each move — and the brackets sit on ~5–5.5 s. Honest caveat: with
  ~1.55 s crops the pixels alone cannot prove ≥5 s; code + brackets together do.
  `theTabAverageComesFromAWindow` pins the window arithmetic.

**4. Chip, Sessions tag, tooltips unchanged — PASS.** `git show --stat 0bbb4b6c` touches only
`src/PaneUsage.{cpp,h}`, `src/RelayWindow.h`, `tests/paneusage_test.cpp` and docs —

**6. No-terminal-pane tab carries no suffix; `appearance/pane_usage` off clears it; both
recover — PASS** (live for the setting, code-read for the Sessions-only tab, as the checklist
allows). Live: `sed` of `relay.conf` to `pane_usage=false` → within ~4 s the label OCRs `pj (2)`
with **no cpu/mem text at all** (`qa-codex-tab-meters-off.png`) while the pane count stays;
back to `true` → the suffix returns (`qa-codex-tab-meters-on.png`: `pj (2) · cpu 00% · mem 00%`).
Code: `refreshPaneStatus()` clears `usageText` when `!meters || !terminal` and resets the tab's
`TabUsageState` (fresh window, `labelledAtMs == 0`), so the first poll after recovery labels at
once; `tabUsageSuffix()` returns `{}` when `metersEnabled()` is false and finds no `Pane` leaf to
seed from otherwise. A Sessions-only tab (all leaves tool panes) has `terminal == false` → the
poll clears the suffix and `tabUsageSuffix()`'s leaf loop returns `{}`; it was not exercised
live because such a tab cannot be made to persist (closing the last terminal pane closes the
tab; a Sessions tool pane closes with its owner), so the state is transient by construction.

- idle: `pj (2) · cpu 00% · mem 00%` (`qa-codex-tab-idle.png`);
- after Ctrl+W closed the second pane: `pj · cpu 00% · mem 00%` — "(2)" gone

Width stability while the numbers changed: the trimmed bounding box of the label's text region

(`"  ·  %1"` → `" (%1)"`, still gated on `panes > 1`), with the usage suffix appended after it.
