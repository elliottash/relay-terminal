Harness notes for whoever repeats this
-----------------------------------------------------------------------------------------
* An isolated XDG_RUNTIME_DIR makes the pane's agent worker exit code 1 ("Failed to reset
  failed state of unit relay-pane-…-agent-1.scope").  `ln -s /run/user/$(id -u)/bus
  $XDG_RUNTIME_DIR/bus` fixes it; harness/env.sh does that.
* A fresh profile opens the welcome dialog and the Approvals pane over whatever is under
  test.  harness/env.sh writes instructions/onboarded, security/approvals_chosen.
* There is no window manager on these Xvfb displays: `xdotool windowactivate` fails,
  `xdotool windowfocus --sync` works.
* Hashing a window region needs the right XWD offsets: bytes_per_line is word 12 (0-based)
  and the pixels start at header_size + ncolors*12, not at header_size.  Getting this
  wrong makes an idle window look like it repaints at 50 Hz — it does not.
* sphinxpad has no `xwd`; `import -window <id> xwd:-` writes the same format (act.py picks).
