# QA evidence in the public repository

Keep screenshots and short, reviewed summaries here. Review text and images for personal
paths, prompts, access codes, tokens, and third-party data before committing them.

Raw request traces, diagnostic logs, and archives belong in the private Relay internal
repository under `qa_evidence/`. Selected older artifacts were moved there on 2026-09-23;
their original paths and hashes are listed in its `qa_evidence/manifest.json`. Some older
public evidence links now refer to relocated artifacts. The public Git history still
contains the previously published versions.
