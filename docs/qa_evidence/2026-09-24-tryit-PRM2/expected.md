In `02-after-429.png`, the dialog tells you the pairing-code request was refused —
the note mentions `429 too many pairing rooms this hour` — and offers an obvious
way forward: a **New code** button. There is no dead typed code still on screen
pretending to work.

A fail answer is right if the refused state looks identical to the working state,
shows a code with no hint it is dead, or gives no visible next step.
