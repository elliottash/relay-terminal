Four decisions before this becomes cards (report §4):

1. Approvals on the Start pane. #K2FV says one screen, before anything else, that cannot be dismissed without choosing. Recommendation: keep the explicit pick but put it as the last row of the Start pane, so a newcomer reads one screen, not two stacked at 400 and 800 ms. Alternative: the Start pane opens after the approvals screen.
2. Which starter tasks ship bundled. Recommendation: all eleven in the report, with "Triage my email" and "Organize multiple subscriptions" shipping as recipes that say "needs a skill" and offer the skills dialog until a bundled skill exists.
3. Does picking a starter task file it as the first Board card? Recommendation: yes when the folder already has a Board; otherwise the recipe runs without one and the project-init question is asked only when the person opens the Board.
4. Does the Start pane carry the switchboard material? #8E4Q permits it for a surface seen once. Recommendation: typography and the two destination colours only, no materials, until #8E4Q is decided.
