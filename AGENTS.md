## Board (Relay)

This project has a Relay board in `issues/`: its cards are the record of what was asked and
what was done, in plain Markdown in git. Read them there or in `issues/BOARD.md`, and leave the
folder out of code searches with `rg -g '!issues/'`.

**Before doing work, read `issues/POLICY.md`** and follow it: check whether the request is already
done, find the card that asks for it or file one, claim it, plan on it if it needs a plan, do the
work, then land it in needs-verification with its evidence. The policy is the same one Relay's own
agents get in their system prompt; `issues/POLICY.md` also says how to do each of their `board_*`
tool calls by editing files, which is what you have.
